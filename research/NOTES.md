## B. Backstage telemetry surface (1.56; verified in node_modules)
- Built-in meters (`@opentelemetry/api`, meter `backstage-plugin-<id>` via alpha MetricsService since 1.49): `catalog_entities_count{kind}`, `catalog_registered_locations_count`, `catalog_relations_count`, `catalog.processed.entities.count{result}`, `catalog.processing.duration`, `catalog.processors.duration`, `catalog.processing.queue.delay`, `catalog.stitching.*`, `scaffolder.task.count/duration{template,result}`, `scaffolder.step.count/duration{template,step,result}`, `backend_tasks.task.runs.*{taskId,scope,result}`, `catalog.events.scm.*`. Histograms in seconds. **Nothing** for HTTP, search, techdocs, auth sign-in, permission, DB pool, users.
- Alpha TracingService (1.51): spans get `backstage.plugin.id`; `backend.tracing.capture.endUser: true` adds `enduser.id`. MCP tools/call spans.
- Auditor (1.36+): winston records with `isAuditEvent: true`, message `plugin.eventId`, fields `plugin, eventId, severityLevel, actor{actorId,ip,hostname,userAgent}, request{url,method}, meta, status (initiated|succeeded|failed), error`. Catalog: entity-fetch{queryType all|by-id|by-name|by-query|by-refs|ancestry}, entity-mutate, entity-validate, entity-facets, location-fetch/mutate/analyze. Scaffolder: task{actionType create|execution|list|get|cancel|retry|stream|events|dry-run|stale-cancel, templateRef, taskId}, template-parameter-schema, action-fetch. auth: offline-sessions-revoke only. kubernetes: resource-fetch/cluster-fetch. mcp-actions: connection/tool-discovery/tool-execution. NOT audited: permissions, search, techdocs. `low` → debug by default: set `backend.auditor.severityLogLevelMappings.low: info`.
- Events service topics: `scaffolder.task`, `experimental.catalog.errors/conflict`. No entity lifecycle topic.
- Frontend AnalyticsApi events: navigate, click, create (value = minutes from `backstage.io/time-saved`), search (value = result count), discover (value = rank), not-found, signIn. New frontend system: `AnalyticsImplementationBlueprint` from `@backstage/plugin-app-react`; context `{pluginId, extensionId, ...}`; `@backstage/ui` components auto-capture click. Existing modules: GA4, Matomo, New Relic Browser, Segment, Quantum Metric, generic HTTP (`@pfeifferj/...`), RHDH adoption-insights. No OTLP module existed → ours is `packages/app/src/modules/analytics/`.
- Logs: winston JSON in production. OTel winston instrumentation needs `@opentelemetry/winston-transport` installed to ship records (otherwise only trace_id injection). `instrumentation-runtime-node` needs Node ≥22.15.

## C. eBPF (OBI v1.0.0, released 2026-10-30) and profiles
- Image `otel/ebpf-instrument:v1.0.0`. Node.js: HTTP/HTTPS (static OpenSSL uprobes in the node binary), Postgres/Redis/gRPC client spans, injected Node agent via inspector (SIGUSR1 + CDP `Runtime.evaluate`): async-hooks context propagation **Stable**, runtime metrics `nodejs.eventloop.*`, `v8js.gc.duration`, `v8js.memory.heap.*`, `v8js.resource.active` (**experimental**, feature `application_runtime`), manual-span bridge (`OTEL_EBPF_NODEJS_MANUAL_SPANS`, only when no SDK). Reads `OTEL_SERVICE_NAME`/`OTEL_RESOURCE_ATTRIBUTES` from the target's env. Resource `telemetry.distro.name=opentelemetry-ebpf-instrumentation`.
- Observed on this Mac (kernel 7.0.14-linuxkit, BTF present): needs `/sys/kernel/tracing` mount; "context propagation is disabled: BPF compensation ineffective (kernel misreports ioctl(FIONREAD))" → no traceparent injection into outgoing plaintext HTTP; async context still works (14-span waterfall incl. Postgres per table + internal catalog HTTP). OBI also instruments its own inspector socket (port 9229) → filtered in Collector. OBI keeps exporting traces even with only a metrics endpoint set → Collector filter keyed on `OBI_TRACES`.
- Limits: no business attributes (template, entity, user), no logs as a signal (log enricher only annotates JSON lines with trace ids; winston untested), TLS egress carries no context, spans may start before parents.
- Profiler: distro image `otel/opentelemetry-collector-ebpf-profiler:0.164.0` (receiver `profiling`, processors incl. `transform`, exporter `otlp_grpc`), gate `service.profilesSupport`. V8 frames symbolized (Ignition/Sparkplug/TurboFan; "asynchronous stack traces are not built"). Pyroscope 2.4 ingests OTLP profiles on :4040. Observed top frames: V8 Exit/Stub frames, ajv `compileSchema`/`validateFunctionCode`, `net.Socket.write`, kernel ext4.
- Collector OBI receiver exists as a separate module (`go.opentelemetry.io/obi/collector`), not in contrib (issue #46192).

## D. Product metrics mapping (what the dashboard does)
- Plugin dimension: OTTL `replace_pattern(url.path, "^/api/([A-Za-z0-9_-]+).*$", "$1")` → `backstage.plugin`; `span_metrics` dims method/status/plugin/route → `traces_span_metrics_calls_total`, `..._duration_milliseconds_bucket`.
- `count` connector: `backstage_audit_events_total{plugin,eventId,status,backstage_actor,backstage_query_type,backstage_action_type,backstage_template}`, `backstage_analytics_events_total{backstage_analytics_action,backstage_plugin,enduser_id}`, `backstage_search_queries_total{backstage_search_zero_results,enduser_id}`.
- Hours saved: Loki `sum_over_time(... | backstage_analytics_action="create" | unwrap backstage_analytics_value [1h]) / 60`.
- Service graph: `service_graph` connector; OBI SQL spans carry `db.namespace=backstage_plugin_<id>` so each plugin's database is a node.
- Prometheus names via OTLP receiver (UnderscoreEscapingWithSuffixes): `http_server_request_duration_seconds_*`, `db_client_operation_duration_seconds_*{db_namespace,db_collection_name,db_operation_name}`, `nodejs_eventloop_utilization_ratio`, `nodejs_eventloop_delay_p99_seconds`, `v8js_gc_duration_seconds_*{v8js_gc_type}`, `v8js_memory_heap_used_bytes{v8js_heap_space_name}`, `postgresql_*`, `obi_network_flow_bytes_total{direction}`, `otelcol_exporter_sent_{spans,log_records,metric_points}`.
- Collector 0.164 component ids: connectors `span_metrics`, `service_graph`, `count`, `routing`, `signal_to_metrics`; processors `filter`, `transform`, `delta_to_cumulative`, `tail_sampling`; exporters `otlp_grpc`, `otlp_http` (old aliases deprecated).
